# Frontend Track — Spec Seed Brief

> This directory is owned by **Chat 1 (Frontend)**.
> Your first task is Phase 1: Intake & Clarify — read this brief and the project
> constitution (`/specs/constitution.md`), then draft your own `requirements.md`,
> `design.md`, and `tasks.md` before writing any implementation code.

## Scope
- All page routes under `/app/(pages)/`
- Design system primitives under `/components/ui/`
- Review session UI under `/components/review/`
- Mock fixture data under `/lib/mocks/` (matching types from `/types/index.ts`)

## Key constraint
Until Phase 4 integration, consume mock data from `/lib/mocks/` instead of calling
the real API routes. Mocks must match the shared types exactly.
