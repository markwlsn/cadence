# Cognitive Error Taxonomy

Students improve fastest when they diagnose why an error occurred:

- ⚡ **Misread Question / Rushed**: Prompt misread, missed a NOT/EXCEPT condition.
- 🧠 **Concept Distinction / Distractor Trap**: Confused two similar mechanisms.
- 📖 **Knowledge Gap / Unfamiliar Term**: Missing core definition.
- 🔢 **Multi-Step Execution / Calculation Error**: Formula or step sequencing mistake.
