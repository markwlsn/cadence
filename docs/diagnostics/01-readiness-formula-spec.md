# Diagnostic Exam Readiness Metric

Replaces artificial gamification with an authentic readiness forecast.

## Formula
$$\text{Readiness} = 0.40 \cdot C + 0.35 \cdot A + 0.25 \cdot S$$

Where:
- $C$: Curriculum milestone completion percentage ($0–100\%$)
- $A$: Average assessment score across completed linear quizzes ($0–100\%$)
- $S$: FSRS memory retention stability ($0–100\%$)
