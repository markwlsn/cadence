# Dual UI Architecture (Desktop Web vs. Mobile App View)

Cadence adapts its presentation between desktop workstation study and mobile on-the-go review.

## Desktop Web Mode (`md:` and above)
- Multi-column layout with persistent left navigation and curriculum roadmap.
- Full keyboard shortcuts (Space to flip, 1–4 difficulty ratings).

## Mobile App View Mode (`< md`)
- Frosted glass bottom tab bar (`MobileTabBar`).
- Thumb-reachable touch targets (minimum 44pt).
- Distraction-free full-screen review mode.
