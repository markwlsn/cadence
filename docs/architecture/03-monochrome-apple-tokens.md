# Apple-Grade Monochrome Design System

Cadence strictly enforces a high-contrast monochrome design system to eliminate cognitive distraction during serious academic review.

## Color Tokens
- Background: `--color-bg` (#ffffff / #000000)
- Surface: `--color-surface` (#f5f5f7 / #1c1c1e)
- Border: `--color-border` (rgba(0,0,0,0.1) / rgba(255,255,255,0.15))
- Text Primary: `--color-text` (#1d1d1f / #f5f5f7)
