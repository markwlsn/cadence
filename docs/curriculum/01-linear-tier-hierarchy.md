# Linear Assessment Curriculum Model

Moving away from unorganized flashcard piles, Cadence groups deck material into structured academic milestones.

## Curriculum Tiers
1. **Tier 1: Foundational Quizzes (Quizzes 1, 2, 3)**
   - 5 items each, testing core definitions, terms, and causal links.
2. **Tier 2: Synthesis Long Quizzes (Long Quizzes 1, 2)**
   - 12–15 items integrating cross-chapter relationships.
3. **Tier 3: Comprehensive Mock Exam**
   - 35 items simulating real university and board examination conditions.
