# Realistic Mock Exam Simulation Protocol

The 35-item Comprehensive Mock Exam simulates strict examination hall conditions.

## Simulation Features
1. **Discreet Countdown Timer**: 35:00 minutes with pause/resume controls.
2. **Question Flagging**: `🚩 Mark for Review` allows candidates to triage difficult items.
3. **Question Jump Navigator**: Horizontal drawer enabling immediate navigation between questions.
